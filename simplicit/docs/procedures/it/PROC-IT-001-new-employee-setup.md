# PROC-IT-001: New Employee IT Setup Procedure

**Procedure ID:** PROC-IT-001  
**Title:** New Employee IT Onboarding and System Access Provisioning  
**Department:** Information Technology  
**Effective Date:** January 1, 2026  
**Owner:** IT Director  

---

## 1. Purpose

To ensure new employees receive timely, appropriate, and secure access to IT systems on or before their first day of employment.

---

## 2. Scope

All new full-time and part-time employees. Contract and temporary worker setup follows an abbreviated version with manager approval required for each access grant.

---

## 3. Prerequisites

- Hiring Manager submits IT Access Request form minimum 5 business days before start date
- Request must include: employee name, start date, job title, department, location, manager name, and standard access profile required

---

## 4. Standard Access Profiles

| Profile | Included Systems |
|---------|-----------------|
| Office Standard | Microsoft 365, Teams, SharePoint, Concur, Paylocity HRIS |
| Engineering | Office Standard + SolidWorks, AutoCAD, PDM system, Engineering SharePoint |
| Manufacturing | Office Standard + MES system, ERP production module (limited) |
| Finance | Office Standard + ERP (Finance module), Concur Admin |
| Sales | Office Standard + Salesforce CRM, Customer portal |
| IT Admin | Full system access — requires IT Director approval |

---

## 5. Setup Steps

### Day -5 (5 Business Days Before Start)
| Step | Task | Owner |
|------|------|-------|
| 5.1 | Create user account in Active Directory | IT Helpdesk |
| 5.2 | Provision Microsoft 365 license (email, Teams, SharePoint) | IT Helpdesk |
| 5.3 | Configure MFA enrollment (send welcome email with setup link) | IT Helpdesk |
| 5.4 | Provision ERP access per profile | IT Systems Admin |
| 5.5 | Prepare laptop (image, encrypt, enroll in MDM) | IT Helpdesk |
| 5.6 | Order any peripheral equipment (monitor, keyboard, etc.) | IT Helpdesk |

### Day 1
| Step | Task | Owner |
|------|------|-------|
| 6.1 | Issue laptop and accessories; confirm user can log in | IT Helpdesk |
| 6.2 | Walk through MFA enrollment in person | IT Helpdesk |
| 6.3 | Confirm all required system access is functional | IT Helpdesk |
| 6.4 | Provide quick-start guide and IT Help Desk contact info | IT Helpdesk |

---

## 6. Access Termination

Upon notification of employee termination from HR, IT must:
- Disable Active Directory account within 2 hours of official termination
- Revoke all system access within 4 hours
- Retrieve company hardware within 24 hours (coordinate with manager)
- Archive email for 90 days per retention policy
